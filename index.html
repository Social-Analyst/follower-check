Follower Check

Runs inside your own logged-in Instagram tab. No password is entered here and nothing is sent to any server.

Step 1: Copy the tool (once)

Step 2: Save it as a bookmark (once)

  1. Chrome on Android: tap the menu, then the star to bookmark this page. Open Bookmarks, long-press it, choose Edit, rename it to Follower Check, and paste the copied code into the URL box.
  2. Safari on iPhone: tap Share, then Add Bookmark. Open Bookmarks, tap Edit, tap the bookmark, rename it Follower Check, and paste the code into the address.
  3. Computer: bookmark this page, edit it, and paste the code into the URL.

Step 3: Use it

  1. Open instagram.com in Chrome or Safari, not inside the Instagram app, and log in normally.
  2. On the Instagram page, run the bookmark. On Chrome Android, type Follower Check in the address bar and tap the bookmark suggestion. On iPhone, open Bookmarks and tap it. On a computer, click it in the bookmarks bar.
  3. Wait while it reads your lists, about a minute for large accounts. Then use the Non-Followers, Mutual Friends and Fans tabs. Tap any name to open the profile.
